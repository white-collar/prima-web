# PRIMA Web — сфероїдична геодезія в браузері

[![Test and deploy](https://github.com/white-collar/prima-web/actions/workflows/pages.yml/badge.svg)](https://github.com/white-collar/prima-web/actions/workflows/pages.yml)

[English](README.md) | **Українська**

**Відкрити застосунок: https://white-collar.github.io/prima-web/**

Вебверсія `PRIMA.EXE` — DOS-програми *«Решение задач сфероидической геодезии»*
(Розв'язання задач сфероїдичної геодезії, Borland Pascal 7, 1992). Вона розв'язує класичні задачі
сфероїдичної геодезії на **еліпсоїді Красовського 1940 року**. Обчислювальний модуль перенесено з
[prima-go](https://github.com/white-collar/prima-go), формули якого відновлено з виконуваного файлу
оригіналу та звірено з ним.

## Можливості

- Усі 13 екранів оригіналу в тому самому дереві меню:
  - **Елементи еліпсоїда:** радіуси N, M, R, rB і RA; дуги меридіанів і паралелей; рамки та площа знімальної трапеції.
  - **Головні геодезичні задачі:** пряма задача (Шрейбер, Рунге–Кутта–Мерсон) та обернена задача (формули із середніми аргументами).
  - **Перетворення координат:** Гаусс–Крюгер в обидва боки, зближення меридіанів, поправки за перехід з еліпсоїда на площину.
- Знак **?** біля кожного заголовка показує коротке пояснення методу та його формули.
- Таблиці, які можна редагувати, як в оригіналі: результати з'являються, щойно рядок заповнено. <kbd>Enter</kbd> переходить до наступної клітинки.
- Кути можна вводити як `55 45 10.5`, `55°45'10.5"` або `55.7529`.
- Інтерфейс англійською, російською та українською; світла й темна теми; працює на телефонах.
- Таблиці зберігаються у браузері. Імпорт/експорт CSV (відкривається в Excel) і друк.
- Звичайні HTML, CSS і JavaScript: без збирання, без залежностей, без сервера.

## Структура

| Шлях | Вміст |
|---|---|
| `index.html`, `css/style.css` | сторінка та стилі |
| `js/geodesy.js` | обчислювальний модуль (перенесення `prima-go/geodesy`) |
| `js/screens.js` | дерево меню, стовпці таблиць, приклади, що обчислює кожен екран |
| `js/help.js` | коротка теорія та формули для підказки «?» кожного екрана |
| `js/i18n.js` | тексти інтерфейсу EN / RU / UA |
| `js/app.js` | дерево меню, редактор таблиць, перемикання мови й теми |
| `tests/` | тести модуля та еталонні дані |

## Локальний запуск

Відкрийте `index.html` у браузері або запустіть сервер у теці:

```bash
python3 -m http.server 8000
```

## Тести

Модуль перевіряється двома способами:

- порівнянням з **350 еталонними результатами порту на Go** з відносною точністю 10⁻¹¹;
- порівнянням з **47 результатами, які показує оригінальна PRIMA.EXE** (запущена в DOSBox-X), у межах її округлення.

```bash
node --test tests/*.test.js
```

Кожне надсилання в `main` запускає тести і, якщо вони успішні, публікує сайт на GitHub Pages.

## Відмінності від оригіналу

- **Перехід з площини на еліпсоїд зберігає знак y.** Оригінал використовував `|Y − Y0|`, тому `l` завжди виходило додатним. Ця версія також приймає `L0` і показує `L = L0 + l`.
- **Немає файлів даних.** Замість файлів `*.LB1`…`*.LBB` оригіналу таблиці зберігаються у браузері й експортуються в CSV.
